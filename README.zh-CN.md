# PDF Camera

**免费 · 离线 · 隐私安全 · 无水印**

一款原生 iPhone 拍照转 PDF 应用。扫描作业、笔记、票据和文档，或从相册选择照片，整理页面后直接保存到「文件」App。

**[English](README.md)** · [隐私说明](PRIVACY.md) · [验证记录](VALIDATION.md) · [MIT 许可证](LICENSE)

## 为什么选择 PDF Camera？

| 特点 | 具体含义 |
|---|---|
| **免费** | 无订阅、无付费转换服务、无广告、无内购，源代码采用 MIT 许可。 |
| **离线** | 扫描、编辑、预览和生成都在手机上完成，保存到「我的 iPhone」无需服务器。 |
| **隐私安全** | 无账号、无统计 SDK、不上传照片或 PDF；临时图片使用 iOS 文件保护，并排除备份。 |
| **无水印** | 导出页面不叠加应用 Logo、品牌标识或水印，保留你的内容。 |

这里的“隐私安全”描述应用的本地处理与权限设计，不代表对任何设备、系统或第三方文件服务作绝对安全保证。

## 已有功能

- 使用 Apple 原生扫描器连续扫描多页，拍摄时识别边缘并调整透视。
- 按选择顺序导入 JPEG、PNG、HEIC 等系统支持的静态图片。
- 扫描页和照片混合使用，支持继续添加、排序、旋转、恢复旋转和删除。
- 生成 A4 PDF，自动适配横竖方向、保持比例并留白。
- PDF 预览、自定义文件名、处理进度、系统「文件」导出。
- 英文与简体中文，跟随系统浅色／深色模式。
- 仅使用 Apple 系统框架，无第三方依赖和后端服务。

## 使用流程

**扫描／导入 → 整理页面 → 命名 → 预览 → 保存到文件**

离线导入前，请确保照片原图已下载到手机；保存时选择「我的 iPhone」。仅存在 iCloud 的照片可能需要系统选择器联网下载。云盘或第三方文件提供商的联网和同步行为由对应服务负责。

## 编译与安装

需要安装 Xcode 的 Mac，以及运行 **iOS 17 或更新版本**的 iPhone。Xcode 必须支持手机上的 iOS 版本。模拟器可验证照片与 PDF 流程，拍照扫描需要真机。

1. 打开 `Photo2PDF.xcodeproj`，选择 **Photo2PDF** scheme。
2. 在 **Xcode → Settings → Accounts** 添加自己的 Apple 账号。
3. 在 **Targets → Photo2PDF → Signing & Capabilities** 勾选 **Automatically manage signing**，选择自己的 Team。公开源码中不包含个人签名配置。
4. 根据需要修改 Bundle Identifier，确保在自己的账号下唯一。
5. 连接并解锁 iPhone，信任 Mac，在 Xcode 选择手机并点击 **Run**；按提示开启开发者模式、信任开发者证书。

使用免费的 **Personal Team** 可以在个人设备安装测试，无需购买付费会员。Apple 说明此类描述文件签发 **7 天**后到期，需要重新编译安装；首次签名和续签可能需要联网。[Apple 官方账号说明](https://developer.apple.com/help/account/basics/about-your-developer-account)

本仓库提供**源代码**，不是 App Store 下载，也不提供可供所有手机直接安装的已签名 IPA。工程与模块名沿用 `Photo2PDF`，安装后的应用名称是 **PDF Camera**。

## 隐私与本地文件

应用不包含主动网络请求，图片和 PDF 在本机处理。扫描时申请相机权限；选择照片使用系统照片选择器，无需访问整个相册。具体边界见[隐私说明](PRIVACY.md)。

临时源文件与正式导出文件分开存放。保存成功或放弃文档后清理临时文件，异常退出遗留内容会在下一次进程启动时清理。**不支持跨启动恢复草稿**，退出前请导出。已保存的 PDF 由「文件」App 或所选文件提供商管理。

## 项目结构

`Models` 保存数据模型，`ViewModels` 管理导入与转换状态，`Views` 提供原生界面，`Services` 处理本地文件与逐页 PDF 渲染，`Utilities` 保存文件名与排版规则。`en.lproj`、`zh-Hans.lproj` 提供两种语言。`Photo2PDFTests` 是自动测试，`Checks` 是可独立运行的检查程序。
